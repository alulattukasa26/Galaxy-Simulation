ENG:
This is my first public online project; I hadn't done any programming before. I started learning Python just a week ago and decided to become a multi-language developer.
The project itself is about how galaxies are structured (though it’s not quite as realistic as actual galaxies!).
W/S Zoom In/Out
L - show gravy lines
V - show velocity color (Blue-to-yellow gradient)
Hold the mouse wheel to move the camera.
Up arrow/Down arrow - Increase simulation speed/Decrease
ENTER - Enter state
All available states:
random – generates a random galaxy state
milkyway – Milky Way galaxy state (poor resemblance)
andromeda – Andromeda galaxy state (may not look very similar)
sombrero – Sombrero galaxy state (may also not look very similar)
meteor – neutron stars with a mass of 350 fly in from random directions
cluster – galaxy state with star clusters
Just a heads-up: the galaxy might not look like a real one—this is my first project...

RUS:
Это мой первый публичный онлайн-проект; раньше я не занимался программированием. Я начал изучать Python всего неделю назад и решил стать разработчиком, владеющим несколькими языками программирования.
Сам проект посвящен структуре галактик (хотя они и не совсем реалистичны по сравнению с настоящими!).
W/S — приближение/удаление (зум).
L — показать линии гравитации.
V — отобразить скорость цветом. (градиент от синего к желтому)
Удерживайте колесико мыши для перемещения камеры.
Стрелки «Вверх»/«Вниз» — увеличить/уменьшить скорость симуляции
ENTER — выбор режима (состояния)
Доступные режимы:
random — генерация случайной галактики.
milkyway — галактика Млечный Путь (схематичное сходство).
andromeda — галактика Андромеды (может быть мало похожа на оригинал).
sombrero — галактика Сомбреро (также может быть мало похожа на оригинал).
meteor — нейтронные звезды массой 350, летящие с разных направлений.
cluster — галактика со звездными скоплениями.
Сразу предупрежу: галактика может не выглядеть как настоящая — это мой первый проект...
